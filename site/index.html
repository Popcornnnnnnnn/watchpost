Four Core Engineering Guardrails

Built so an autonomous coding agent stays genuinely helpful in noisy real-world work chats without ever embarrassing you or breaking production silently.

SAFE EXECUTION

4-Mode Triage & "go" Approval Gate

Classifies incoming messages into Q&A, Advice, FYI, or Bug under per-channel autonomy (assistant_only, diagnose_only, auto_fix). High-impact edits pause until you reply go, or skip to dismiss cleanly.

NOISE CONTROL

Quiet Hours & Morning Briefing

Suppress pings overnight (such as 23:00–08:00) while diagnosing quietly into SQLite kv_state, then flush one morning digest at 08:00. Configurable urgent keywords still break through on real emergencies.

CONTEXT RECALL

Cross-Channel Memory + Isolation

Feeds recent incident summaries from sibling channels in the same repository (for example Support in WeCom + Dev in Slack) while keeping owner_direct personal sessions strictly sealed off.

RESILIENCE

Hot Reload & Backup Agent Failover

Reload channels, personas, and Quiet Hours in milliseconds with POST /api/reload or SIGHUP, recover active threads cleanly after crashes, and automatically fail over from Antigravity to Codex or Claude Code.

Quickstart, SDK & Local Sandbox

Start with one guided wizard command, test your plugin with automated conformance checks, or simulate colleagues and phone replies offline in your browser.

bash · Setup Wizard 
git clone https://github.com/Popcornnnnnnnn/watchpost.git && cd watchpost
uv sync --all-extras

# Writes 0600 ~/.config/watchpost/config.json with ${ENV_VAR} placeholders
uv run watchpost setup

uv run watchpost channels list-remote --adapter slack
uv run watchpost doctor && uv run watchpost run --api-port 8787
bash · Scaffold & Conformance Check 
# Scaffold a custom adapter or notifier powered by watchpost.sdk
uv run watchpost plugins scaffold --kind channel --name my_bridge --dest ./plugins/my_bridge

# Automated schema + contract verification (supports WhatsApp bridge template too)
uv run watchpost plugins check --kind channel --test-fetch --cmd python3 ./plugins/my_bridge/plugin.py
uv run watchpost plugins check --kind channel --test-fetch --cmd python3 examples/whatsapp_plugin_template.py
bash · Offline Simulator & Test Suite 
# 2-column browser simulator: act as colleagues on left, steer/approve on right
uv run watchpost sandbox-ui --backend mock

# Or point a real local CLI agent at a repository safely in read-only mode
uv run watchpost sandbox-ui --backend codex --cwd /path/to/repo --autonomy diagnose_only

# Run the offline unit & webhook verification suite (51 tests)
uv run pytest -q tests/
bash · Signed Webhooks & Hot Reload 
# Zero-downtime hot reload of channels, personas, Quiet Hours & debounce timings
curl -s -X POST http://127.0.0.1:8787/api/reload

# Trigger or inspect Quiet Hours & Morning Briefing
curl -s http://127.0.0.1:8787/api/quiet
curl -s -X POST http://127.0.0.1:8787/api/brief

# Fail-closed signed webhook receivers built into watchpost run --api-port 8787:
#   POST /api/webhooks/dingtalk   (HMAC-SHA256 timestamp + sign headers)
#   GET|POST /api/webhooks/wecom  (SHA1 msg_signature verification)
